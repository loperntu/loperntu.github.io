LLM 的微分幾何

從流形、度量與疊加，理解機制可解釋性

謝舒凱　編審*

機制可解釋性（mechanistic interpretability）想打開模型，看懂它內部的表示。線性代數篇把表示當成向量與方向；但表示所在的空間可能是彎的，距離未必能用直尺量，方向的數量甚至可能超過維度。本篇分流形、度量、疊加與特徵三章，以二維圖示類比高維情形，重直觀而不求嚴格。建議先讀線性代數篇與微積分篇。

第 1 章

流形

Manifolds

模型的隱藏狀態住在幾千維的空間裡，但它們並不是均勻散布的。本章介紹描述「彎曲、低維結構」的語言。

1.1流形：局部平坦的彎曲空間

地球是圓的，但你家門前的路看起來是平的。

流形（manifold）：在每一點附近看起來都像平坦 維空間的形狀。圓是一維流形，球面是二維流形；它們可以「住」在更高維的空間裡。

內在維度（intrinsic dimension）：描述流形上的一點需要幾個數字。圓上的點只需要一個角度，所以內在維度是 1，即使它畫在二維平面上。

流形假說（manifold hypothesis）：真實資料雖然寫在高維空間裡，實際上集中在一個維度低得多的流形附近。

一個具體的例子：Engels 等人（2024）在 GPT-2 與 Mistral 7B 裡發現，「月份」與「星期幾」的表示排成一個圓：一月、二月……依序繞行，十二月之後又接回一月。

動手試試

點選圓上的兩個月份（先起點、後終點）。紅虛線是直線距離，藍弧是沿著流形走的距離：

LLM 視角

若只用「直線」的眼光看表示，就會錯過這種結構。在一月與七月之間做線性內插，中點落在圓心附近，而模型可能從沒見過那裡的表示。機制可解釋性裡「特徵是方向」的線性表示假說，對許多概念成立，但不是全部。

1.2切空間與雅可比矩陣

在夠小的範圍內，彎曲的流形可以用平面近似。

切空間（tangent space）：流形在點 附近的最佳線性近似，例如曲線的切線、曲面的切平面。它是 微積分篇 1.3 線性近似的高維版本。

雅可比矩陣（Jacobian）：多變數函數的「導數」。它把輸入的小位移 ，線性地映成輸出的位移：

這給了線性方法一個合理的位置：即使整個模型高度非線性，在某個輸入附近，它的行為仍能用一個矩陣描述。只是這個矩陣會隨位置改變：在 找到的「特徵方向」，拿到 未必適用。

LLM 視角

許多歸因方法（例如「梯度 × 輸入」、積分梯度）都建立在梯度之上，而梯度正是雅可比矩陣的一列。它們回答的是「輸入的這一維推一點點，輸出會變多少」，解釋的是模型在這個輸入附近的行為，而不是整體。

第 2 章

度量

Metrics

線性代數篇用內積定義長度、角度與「正交」。但內積不只一種；選哪一種，決定了我們說兩個概念「無關」時到底是什麼意思。

2.1度量張量與黎曼度量

兩個方向是否正交，取決於你用什麼尺來量。

黎曼度量（Riemannian metric）：在流形的每一點都指定一個度量張量 ，並隨位置平滑變化。有了它，就能在彎曲的空間裡量長度與角度；兩點之間最短的路徑稱為 測地線（geodesic），1.1 圓上的藍弧就是一例。

這在 LLM 裡有實際的意義。Park 等人（2023）指出，要讓概念方向之間的「正交」符合模型的因果行為，應該使用由反嵌入向量的共變異數估計出的「因果內積」，而不是直接用歐氏內積。

LLM 視角

兩個特徵方向用歐氏內積量起來不正交，不代表它們在模型的運作中互相干擾；反之亦然。選對度量，是判斷「兩個概念是否獨立」的前提。

2.3共變異數、白化與馬氏距離

資料在某些方向散得開、某些方向擠在一起；先把它「揉圓」，再來量距離。

共變異數矩陣（covariance matrix）：記錄資料在每一對方向上一起變動的程度。對角線是各維的變異數；非對角線為正，表示兩維傾向同增同減。

白化（whitening）：把資料乘上 ，讓每個方向的變異數都變成 1、彼此不相關，橢圓形的資料雲因此變成圓形。

馬氏距離（Mahalanobis distance）：白化之後量出的歐氏距離。它等於用度量張量 （2.1）來量距離：

LLM 視角

隱藏狀態的共變異數極不均勻：少數幾個「離群維度」的變異數特別大，直接用餘弦相似度比較時常被它們主導。2.1 的因果內積、探針的方向選擇（《Transformer 圖解學習指南》6.2.3），以及概念消除方法 LEACE（同書 6.4.3），都用到了共變異數或它的逆矩陣。

第 3 章

疊加與特徵

Superposition and Features

若每個概念對應一個方向，4096 維的空間最多只能放 4096 個互相正交的概念，但模型顯然知道得更多。本章談模型如何「擠」進更多特徵，以及研究者如何把它們找回來。

3.1疊加：比維度更多的特徵

4096 維的空間，如何裝下數十萬個概念？

疊加（superposition）：讓特徵數 多於維度 ，方向彼此「幾乎正交」。代價是干擾：讀取一個特徵時，會混入其他特徵的一點訊號。

Elhage 等人（2022）的玩具模型顯示：當特徵很稀疏（大多數時候只有少數幾個同時出現）時，干擾很少真的發生，疊加就划算。在二維裡放五個特徵，它們會自己排成正五邊形。

稀疏自編碼器（sparse autoencoder，SAE）：學一本「字典」，也就是 個方向 ，讓每個激活向量都能寫成其中少數幾個方向的加權和：

字典裡的方向往往對應人類看得懂的概念。把某個方向在殘差流中放大或縮小（線性代數篇 3.2 的導向向量），就能觀察模型行為如何跟著改變。

LLM 視角

Anthropic 的「Towards Monosemanticity」（2023）與後續在 Claude 3 Sonnet 上的研究，用 SAE 找出了數百萬個特徵，例如對金門大橋、程式錯誤或諂媚語氣起反應的方向。但 SAE 假設特徵是線性方向；對 1.1 那種圓形結構，就得把幾個方向合起來看，才能還原完整的幾何。

讀出、寫入、刪除、修改這四種介入，用的是同一組幾何操作。
