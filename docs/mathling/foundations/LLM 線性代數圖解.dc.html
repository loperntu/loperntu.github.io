向量與相似度

Vectors and Similarity

模型看不懂文字，只看得懂數字。本章說明詞元如何變成一串數字，以及如何衡量兩串數字「像不像」。

1.1向量與嵌入

一個詞元，就是高維空間裡的一個點。

向量（vector）：一串有順序的數字 。可以看成空間中的一個點，也可以看成從原點出發的一支箭頭。

嵌入（embedding）：模型替詞彙表裡的每個詞元配一個 維向量，排成一張 的表 。讀入第 個詞元，就是取出第 列。

這些數字一開始是隨機的，在訓練中逐步調整，讓用法相近的詞元落在相近的位置。

1.3範數與正規化

向量有多長，以及如何把它拉回標準長度。

範數（norm）：向量的長度。最常用的是 L2 範數：

RMSNorm：把向量除以它的均方根（root mean square），再乘上可學習的縮放向量 ：

它和 統計篇 2.1 的 LayerNorm 很像，只是省略了「減去平均」這一步。正規化之後，向量的均方根變成 1，長度約為 。

Python
import numpy as np
v = np.array([3.0, -4.0, 0.0, 12.0])
np.linalg.norm(v)                         # 13.0
def rmsnorm(v, gamma=1.0, eps=1e-6):
    return v / np.sqrt((v ** 2).mean() + eps) * gamma
rmsnorm(v)                                # 均方根變為 1，方向不變
LLM 視角

Llama 等模型在每個子層之前都做 RMSNorm。正規化後，下一層看到的主要是向量的方向，而不太受長度影響，這也是機制可解釋性常以「方向」討論特徵的原因之一（見 幾何篇）。

矩陣與變換

Matrices and Transformations

向量是模型裡的「資料」，矩陣則是模型裡的「動作」。Transformer 的絕大部分計算，都是矩陣乘上向量。

第 3 章

分解與子空間

Decompositions and Subspaces

把矩陣拆開來看，就能知道它主要在哪些方向上起作用；把向量空間切成子空間，就能理解模型各層如何分工。

3.1特徵值與奇異值分解

任何矩陣，都可以拆成「旋轉、拉伸、再旋轉」。

特徵向量（eigenvector）：被矩陣作用後方向不變、只被縮放的向量，；縮放倍數 稱為特徵值（eigenvalue）。

奇異值分解（singular value decomposition，SVD）：任何矩陣都能寫成三個矩陣的乘積：

先旋轉， 沿座標軸拉伸（對角線上是奇異值）， 再旋轉一次。只保留前 個最大的奇異值，就得到最接近 的秩 矩陣（Eckart–Young 定理），這也是 2.3 低秩近似的理論依據。

LLM 視角

研究者分析權重時，常看奇異值的分布：若少數幾個特別大，代表這個矩陣主要只在少數方向上起作用。對某一層的激活值做 SVD（即主成分分析），也是找出表示中「主要變化方向」的第一步。

3.2子空間、投影與殘差流

模型的每一層，都在同一條資訊高速公路上讀寫。

子空間（subspace）：由幾個向量張成的直線、平面或更高維的「平面」。一個 維空間可以容納許多彼此正交、互不干擾的子空間。

LLM 視角

這種「讀寫殘差流」的觀點，是機制可解釋性（mechanistic interpretability）的基本框架。所謂導向向量（steering vector），就是在殘差流中加入某個方向，讓輸出偏向特定概念；線性表示假說則主張，許多概念都對應殘差流中的一個方向。這些方向為什麼能比維度還多、在彎曲的空間裡又該怎麼量，是 幾何篇 的主題。
