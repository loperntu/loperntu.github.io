二階導數（second derivative）：斜率本身的變化率，描述曲線彎得多厲害。把它加進來，近似更準：

這就是學習率不能太大的原因：梯度只保證「在附近」往下。步子一大，第二項（曲率）就會主導。多變數時，所有二階偏導數排成的矩陣稱為 海森矩陣（Hessian）；上一節的橢圓一邊陡、一邊緩，就是海森矩陣在兩個方向上的曲率不同。

LLM 視角

LLM 訓練常用的 Adam 優化器，會依每個參數過去梯度的大小自動縮放步長，某種程度上彌補了「各方向曲率不同」的問題。學習率暖身（warm-up）則是在訓練初期、地形最難捉摸時，先走小步。

連鎖律與反向傳播

The Chain Rule and Backpropagation

神經網路是許多簡單函數一層層疊成的。要對這樣的組合求導，靠的是連鎖律；把連鎖律有系統地執行一遍，就是反向傳播。

LLM 視角

Transformer 有幾十層，每層又由注意力、前饋網路與正規化組成。損失對第一層某個權重的導數，就是沿著這條長鏈，把每一段的局部導數乘起來。

2.2計算圖與反向傳播

先往前算出答案，再往回分配責任。

計算圖（computational graph）：把一個計算拆成節點，每個節點只做一個簡單運算（加、乘、平方……）。

反向傳播（backpropagation）：先做一次前向計算，記下每個節點的值；再從損失出發往回走，每個節點把「上游傳來的梯度」乘上自己的局部導數，繼續往下傳：

{{ bp.phase }}{{ bp.txt }}

附註：反向傳播只要一次前向、一次反向，就能得到所有參數的梯度，成本和前向計算同一個量級。若改用「每個參數各推一下看看」的數值微分，70 億個參數就得做 70 億次前向計算。

Python
import torch
w = torch.tensor(0.5, requires_grad=True)
b = torch.tensor(0.3, requires_grad=True)
x, y = 2.0, 2.0
loss = (w * x + b - y) ** 2    # 前向：0.49
loss.backward()                # 反向傳播
w.grad, b.grad                 # (-2.8, -1.4)，和上圖一致
LLM 視角

PyTorch、JAX 等框架的「自動微分」，就是在背後建立計算圖、執行反向傳播。前向時必須暫存每一層的中間值（activations），這是訓練比推論更吃記憶體的主要原因之一。

2.3梯度消失與梯度爆炸

很多個數連乘，結果不是趨近 0，就是一飛衝天。

梯度消失（vanishing gradient）：若每一層的局部導數都小於 1，連乘幾十層之後，傳到前面幾層的梯度幾乎為 0，那些層就學不動。

梯度爆炸（exploding gradient）：反之，若都大於 1，梯度會指數成長，一次更新就可能讓模型崩壞。

殘差連接（residual connection）：把每一層改成 ，局部導數就變成 。即使 很小，梯度也能透過那個「1」直接流回前面。

LLM 視角

早期的循環神經網路（RNN）深受梯度消失之苦，很難記住長距離的資訊。Transformer 的每個子層都包在殘差連接裡，再加上 LayerNorm 與梯度裁剪（gradient clipping，把過長的梯度縮到固定長度），才能穩定地疊到上百層。

第 3 章

LLM 裡的導數

Derivatives Inside an LLM

最後來看幾個在 LLM 訓練中每一步都被微分的函數：讓網路有非線性能力的激活函數，以及位在最末端的 softmax 與交叉熵。

3.1激活函數與它們的導數

非線性讓網路能表達複雜規律；它的導數決定梯度能否通過。

ReLU：。導數在 時是 1、 時是 0，所以梯度要嘛原樣通過，要嘛完全被擋住。

GELU：， 是標準常態的累積分布函數（統計篇 2.1）。它是 ReLU 的平滑版，負值區也留有一點梯度。

Sigmoid：，導數 最大只有 0.25，兩端趨近 0，這是早期深層網路梯度消失的主因之一。

LLM 視角

這個梯度 就是反向傳播的起點：它從輸出層出發，經由 2.2 的機制傳回模型的每一個權重。每讀一個詞元，模型就把正確答案的分數往上推一點、把其他候選往下壓一點；預訓練中數兆次的更新，做的都是這件事。
